# 🛒 Blinkit Sales Analysis | Python Project

## 📌 Project Overview

This project focuses on analyzing Blinkit sales data using Python to understand product performance, outlet characteristics, sales distribution, and customer ratings.

The project involves data analysis, KPI calculations, and data visualization to transform raw sales data into meaningful business insights.

Two dashboard versions were developed as part of this project: an initial sales analysis dashboard and an advanced dashboard with an improved dark theme, enhanced colour combinations, and a more structured visual layout.

## 🛠️ Tools and Technologies

- **Python** – Programming language for data analysis.
- **Pandas** – Data manipulation and analysis.
- **NumPy** – Numerical computations and array operations.
- **Matplotlib (Pyplot)** – Creating charts and visualizations.
- **Seaborn** – Statistical data visualization.
- **Jupyter Notebook** – Development environment.
- **CSV** – Dataset format.

## ⭐ Key Features

- Imported and analyzed Blinkit sales data using Python.
- Worked with 8,523 records and 12 columns.
- Performed data analysis and KPI calculations.
- Analyzed sales based on item types and fat content.
- Compared sales performance across different outlet types.
- Examined outlet size and location-wise sales distribution.
- Analyzed outlet establishment trends.
- Created multiple charts and visualizations.
- Developed an initial analysis dashboard.
- Redesigned the dashboard with a professional dark theme.
- Integrated KPI cards and multiple charts into the final dashboard.

## 📈 Key Insights

### Key Performance Indicators (KPIs)

- **Total Sales:** 1,201,681
- **Average Sales:** 141.0
- **Total Items Sold:** 8,523
- **Average Customer Rating:** 4.0

### Additional Observations

- Low-fat products contribute a larger share of sales compared to regular-fat products.
- Sales performance varies across different item categories.
- Outlet size and location type show differences in sales contribution.
- Medium-sized outlets contribute a significant share of total sales.
- Outlet establishment trends show variations in sales performance across different years.

The main objective of this project is to analyze Blinkit's sales data using Python, identify meaningful patterns in product and outlet performance, calculate important business KPIs, and present the findings through informative and visually appealing dashboards.
